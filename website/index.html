Hanya di Peeko

Gulir untuk pindah, dengan gerak pegas.

Tidak ada deretan tab yang perlu dibidik. Gulir di mana saja di panel untuk berganti tampilan; gulir cepat untuk melompat beberapa sekaligus. Notch melebar dan menyusut mengikuti isinya, bahkan kalau arahnya berubah di tengah jalan.

  • Kedip, mata Peeko, berkedip dan tersenyum saat ada kabar baik
  • Jadi garis tipis saat jendela menempel ke atas, dan menyingkir saat layar penuh
  • Win + Alt + C untuk membuka dari keyboard

Timer fokus

Pomodoro dengan istirahat otomatis. Sisa waktunya tetap terlihat di notch, dan tetap akurat walau laptop sempat sleep.

Pengingat minum

Ingatkan tiap interval, catat gelas dengan satu klik langsung dari notch.

Tugas

Daftar singkat untuk hari ini. Yang sudah dicentang bersih sendiri besok.

Kontrol cepat

Wi-Fi, Bluetooth, Jangan ganggu, volume, kecerahan, tangkap layar, dan kunci layar.

Hari ini

Kalender bulan ini, cuaca kotamu dari Open-Meteo, dan baterai.

Kabar sekilas

Volume, kecerahan, Caps Lock, ganti bahasa keyboard, baterai, Wi-Fi, dan headphone muncul sebentar di notch.

Unduh

Klik tombol di bawah untuk mengunduh Peeko-…-win-x64.zip dari GitHub Releases.

Ekstrak

Klik kanan zip → Extract All. Simpan foldernya di tempat tetap, misalnya Documents, supaya update otomatis bisa bekerja.

Jalankan

Klik dua kali Peeko.exe. Kalau muncul “Windows protected your PC”, pilih More info → Run anyway. Dua mata kecil muncul di tengah atas layar.

Unduh Peeko

Butuh Windows 10 versi 2004 atau lebih baru. Tidak perlu memasang apa-apa lagi. Baca panduan lengkap.

FAQ

Pertanyaan yang sering muncul.

Apakah Peeko gratis?

Ya, gratis selamanya dan kode sumbernya terbuka di GitHub dengan lisensi GPLv3. Siapa pun boleh membaca, memperbaiki, dan mengusulkan fitur.

Kenapa Windows menampilkan peringatan SmartScreen?

Peeko belum memakai sertifikat code signing berbayar, jadi Windows belum “mengenalnya”. Pilih More info → Run anyway; peringatannya hanya sekali. Kalau ragu, kode sumbernya bisa kamu periksa sendiri.

Bagaimana cara update?

Peeko mengecek versi baru sendiri. Kalau ada, mata di notch berganti menjadi tombol Update; klik, dan Peeko mengunduh, memasang, lalu menyala lagi. Pengaturan dan datamu tetap ada.

Data apa yang dikirim ke internet?
  • Judul, artis, dan durasi lagu ke lrclib.net untuk mengambil lirik (bisa dimatikan).
  • Koordinat kotamu ke Open-Meteo untuk cuaca (bisa dimatikan).
  • Sekali saja, perkiraan lokasi dari alamat IP lewat ipapi.co bila kota belum diisi.
  • Cek versi baru di GitHub.

Jadwal salat dihitung offline. File yang diubah formatnya tidak pernah diunggah.

Notch-nya menutupi webcam atau tombol jendela.

Buka Pengaturan → Geser horizontal untuk memindahkannya ke kiri atau kanan. Saat jendela seperti Chrome menempel ke atas, Peeko otomatis menjadi garis tipis.

Antivirus memblokir Peeko.

Peeko membaca tombol Caps Lock dan pergantian bahasa keyboard untuk menampilkan kabar sekilas, sehingga beberapa antivirus curiga. Kode untuk itu terbuka di repo; tambahkan Peeko ke pengecualian kalau kamu percaya.

Bagaimana cara menghapusnya?

Klik kanan ikon Peeko di tray → Keluar, matikan “Mulai bersama Windows” bila sempat dinyalakan, lalu hapus foldernya. Data tersimpan di %AppData%\Peeko kalau ingin ikut dihapus.
